# CASA ALMA primary-beam samples

`casa_alma_pb_samples.npz` contains 1024 deterministic samples from each of six
CASA 6.7.7.6 `tclean` primary-beam FITS images from the continuum demonstrator.
They are independent CASA outputs, not values generated by AstroVIPER.

The unmasked datasets are 2017.1.00661.S, 2017.1.00999.S, 2018.1.01079.S,
2018.1.01284.S, 2019.1.00678.S and 2023.1.01342.S. The first and fourth use
7-m/ACA apertures; the other four use 12-m apertures. Frequencies range from
40.149 to 337.438 GHz. Imaging used `gridder='standard'`, MFS, nterms=1, with
matched reference frequencies. Input products were `continuum.pb.fits` under
`casa_benchmark_astroviper_matched` in RADPS_test/continuum_demonstrator/results.

Within each image, finite pixels with PB>0.2 were flattened in l,m order; 1024
indices equally spaced across that selection were retained. Arrays record l,m
offsets in radians derived from FITS CDELT/CRPIX, spectral frequency in Hz,
CASA effective diameter in metres, maximum tabulated radius at 1 GHz in radians,
and actual CASA power response. The selection does not filter on agreement with
AstroVIPER. The regression tolerance is rtol=1e-6, atol=1e-7.

`casa_vla_pb.npz`: full 200 x 200 primary-beam plane from the retained
2026-09-24 harness CASA off-axis MFS reference (`casa_off_axis_mfs.npz`,
`pb_t0`). Legacy VLA refim fixture, 1.5 GHz reference frequency, 10 arcsec
pixels, pointing at pixel (100, 100), default tclean beam. This is independent
CASA output; no AstroVIPER formula was used to generate the reference.

The same archive includes 5120 regularly sampled pixels across all 20 channels
of `casa_images/off_axis_mvc.pb`, with offsets and frequencies taken from the
CASA coordinate record. This cube starts just below 1 GHz in LSRK and selects
CASA VLA_NVSS (24.5 m, no blockage), whereas the MFS plane selects VLA_L.
